# в чем идея программы?
в каждом конфиге для какой то вещи есть файл или группа файлов которые что то делают
для конфига например для emacs есть файл emacs-daemon который сделает сервис сервеса
emacs что бы он был запущен при старте а открывания emacs было быстрым. тоесть
программа просто запускает sh скрипты используя python для автоматизации а в
свою очередь запускает setup этот  python файл
